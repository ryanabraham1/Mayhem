Guide/Getting started

Introduction ​

Mayhem is one desktop app for a robot's software. You build pose-based autos, watch state machines run, analyze match logs, see what code is on the robot, and review what a code change actually does before it goes on the robot, whether a coding agent or a teammate wrote it.

How the pieces fit ​

Mayhem works on the robot code repository you already have. It doesn't replace your code; it reads it and adds a few files next to it.

PieceWhere it livesWhat it does

The workspaces ​

  • Overview: changes waiting for review, routine thumbnails, latest logs, the match-ready checklist and a clickable map of how the robot works.
  • Changes: the branches waiting for review, and what each one does to controls, state machines, values, hardware and autos, with a before/after sim proof.
  • Autonomous: place goals, add actions and conditions, preview the path or the full routine.
  • State machines: graphs in simulation, live over NT4, or replayed from a log.
  • Logs: findings, power, signals and pose replay for every recording.
  • Robot: what's on the robot now, every value in the code, specs, connection and log collection.

What the preview doesn't prove

The auto preview is kinematic. It doesn't run your custom robot code, model traction or avoid obstacles, and the pose controller still has to be tuned on the real robot. See the implementation status for what's been verified.
