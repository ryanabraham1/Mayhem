mayhemlib.runner

TrajectoryRunner ​

final class
public final class TrajectoryRunner

Runs one trajectory: feedforward + saturated feedback, time dilation, bump detection and bridge recovery, auto unbeach, rough-terrain handling, and event markers. Framework-free (no WPILib command dependencies) so it is fully unit testable; AutoFactory wraps it in commands.

Call start once, then update every loop with the latest vision-fused pose.
