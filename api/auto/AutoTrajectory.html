mayhemlib.auto

AutoTrajectory ​

final class
public final class AutoTrajectory

A trajectory (or one split segment) in an AutoRoutine, modeled on Choreo's choreo.auto.AutoTrajectory: a follow command plus triggers for its timeline.

Triggers are polled by the routine, so they only fire while the routine runs. One-cycle triggers (done(), atTime(double), instant markers) are true on the routine poll right after the event happened.
