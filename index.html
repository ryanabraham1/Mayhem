On the robot

A routine in a few lines

Markers you name in the app become triggers in your robot code. Every method is documented in the API reference.

AutoTrajectory reference →
RobotContainer.java
AutoRoutine routine = autoFactory.newRoutine("Hub Cycle");
AutoTrajectory toHub = routine.trajectory("Hub Cycle", 0);

routine.active().onTrue(
    toHub.resetOdometry().andThen(toHub.cmd()));
toHub.atTime("shoot").onTrue(shooter.shootOnce());
toHub.recovering().whileTrue(lights.flash());
