Robot code · C++

The app's IDs, bound in robot code

Actions and conditions you name in an auto become bindings on the runner. Anything left unbound is an error at boot, not a failed step mid-match.

Running autos →
MayhemAutos.cpp
mayhem::AutoRunner runner{routine.View()};
runner.Bind("superstructure.intake",
            mayhem::Instant([&] { intake.Start(); }))
      .BindSignal("superstructure.ready",
            [&] { return mayhem::SignalValue{shooter.Ready()}; });

if (auto missing = runner.UnboundReport(); !missing.empty())
  alert.SetText("Unhandled Mayhem IDs: " + missing);
